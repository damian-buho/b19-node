# Автоматична встановлення npm та збірка

- Залежності встановлюються автоматично, якщо при збиранні є `package.json` — без додаткових налаштувань у Dockerfile.
- Аутентифікація приватних реєстрів здійснюється через секрети BuildKit, ніколи не вбудовуючись в образ.
- Якщо існує скрипт `build`, він виконується автоматично після встановлення — образи виробництва виходять готовими.
- Режим розробки включає залежності розробки; режим виробництва виключає їх.
