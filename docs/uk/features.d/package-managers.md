# Зафіксовані менеджери пакетів

- npm, pnpm та corepack попередньо встановлені з зафіксованими версіями, тож збірки відтворювані.
- Corepack забезпечує доступ за потребою до Yarn та pnpm без окремого встановлення.
- Версії менеджерів пакетів незалежні від версії Node.js, що дозволяє оновлення без зміни runtime.
